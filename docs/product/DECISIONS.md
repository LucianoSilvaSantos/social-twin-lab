# Decisions (ADR)

## ADR-001 - React + Vite + TypeScript

- Status: Accepted
- Decisao: usar React com Vite e TypeScript no frontend.
- Motivo: velocidade de iteracao, tipagem e base moderna para evolucao.

## ADR-002 - Mantine para acelerar UI

- Status: Accepted
- Decisao: adotar Mantine UI e Mantine Hooks.
- Motivo: produtividade na construcao de interfaces consistentes.

## ADR-003 - FastAPI no backend

- Status: Accepted
- Decisao: usar FastAPI como framework principal da API.
- Motivo: simplicidade, performance e integracao natural com Pydantic.

## ADR-004 - Python para base de dominio e simulacao

- Status: Accepted
- Decisao: manter Python como linguagem principal no backend e simulacao.
- Motivo: ecossistema forte em modelagem, ciencia de dados e estatistica.

## ADR-005 - Mesa e NetworkX futuramente

- Status: Accepted
- Decisao: reservar Mesa e NetworkX para as iteracoes de simulacao real.
- Motivo: aderencia ao problema de ABM e redes de influencia.
