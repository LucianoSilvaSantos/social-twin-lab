# Domain Rules

## Regra 1

O sistema nao preve individuos.

## Regra 2

O sistema simula tendencias coletivas provaveis.

## Regra 3

Todo resultado deve ser expresso em termos probabilisticos ou de tendencia.

## Regra 4

Toda simulacao deve salvar parametros de entrada para rastreabilidade.

## Regra 5

Toda recomendacao deve ser tratada como cenario possivel, nunca como verdade absoluta.
