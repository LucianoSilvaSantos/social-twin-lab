# ITERATION_00_FOUNDATION

## Objetivo

Estabelecer a fundacao do projeto com estrutura de frontend, backend e documentacao para evolucao incremental.

## Entregas

- frontend base com AppShell e navegacao
- backend FastAPI com endpoints de saude e mock
- estrutura de modulos de simulacao (stubs)
- documentos de produto, QA, deploy e pesquisa

## Endpoints desta fase

- `GET /health`
- `GET /api/status`
- `POST /api/scenarios/mock-run`

## Regras de Escopo

- sem simulacao real
- sem persistencia real
- sem autenticacao
- sem docker
